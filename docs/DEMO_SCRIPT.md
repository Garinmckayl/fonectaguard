## Q&A answers to have ready
- **"Does an LLM choose the channel?"** The when-and-how is a transparent, tested policy over a calibrated model score, so it is explainable and can't improvise. The LLM is used where language is needed: reading photos, voice and free text.
- **"What did you benchmark?"** Out-of-fold score 63.6 vs baseline 54.5 on the dev labels, 2025 back-test about 60.7, precision about 0.85. A study of 37 real Helsinki cafés for AI-assistant errors.
- **"What's proprietary?"** The feature set and calibration of the hours model, the rules floor, the ladder policy, and the validated-action agent that can only emit a fixed set of checked changes.
- **"Which channels work today?"** See the README. Answer plainly when asked.
